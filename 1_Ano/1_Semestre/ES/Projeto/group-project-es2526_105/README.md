# **Risk & Threat Modelling Platform**
> Accessible at: https://deti-engsoft-05.ua.pt/

A platform that enables security architects, developers, and project managers to systematically identify, assess, and mitigate security threats using the STRIDE (Spoofing, Tampering, Repudiation, Information Disclosure, Denial of Service, Elevation of Privilege) framework throughout the software development lifecycle.
